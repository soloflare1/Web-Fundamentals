
### 🔹 React Component (App.jsx)

```jsx id="a1"
function App() {
  return (
    <>
      <button className='btn-1'>Click Me</button>
      <button style={{ background: 'blue' }} className='btn-1'>Click Me</button>
      <button className='btn-1'>Click Me</button>
    </>
  )
}

export default App;
```

---

### 🎨 CSS File

```css id="a2"
.btn-1{
  padding: 10px;
  background-color: brown;
  border-radius: 10px;
  font-size: 1.2em;
}
```

---

## 🔹 Key Concepts

### ✅ 1. CSS Class (`className`)

* Reusable styling method
* Defined in external CSS file
* Applied using `className`

Example:

```jsx id="a3"
className='btn-1'
```

---

### ✅ 2. Inline Style

* Written directly in JSX
* Uses JavaScript object format

Example:

```jsx id="a4"
style={{ background: 'blue' }}
```

---

## ⚠️ Important Rule

 Inline style has higher priority than CSS class

So:

* CSS: `brown`
* Inline: `blue`
  Final color = **blue**

---

## 🔄 Output Behavior

| Button | Style                       |
| ------ | --------------------------- |
| 1st    | Brown (CSS)                 |
| 2nd    | Blue (inline overrides CSS) |
| 3rd    | Brown (CSS)                 |
