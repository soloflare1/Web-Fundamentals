### 🔹 What is `useState`?

* `useState` is a React Hook
* It is used to **store and update data (state)** inside a component
* When state changes → **component re-renders (UI update)**

---

### 🔹 Syntax

```js
const [state, setState] = useState(initialValue)
```

* `state` → current value
* `setState` → function to update value

---

### 🔹 Example

```js
const [num, setNum] = useState(0)
```

* Initial value = `0`

---

### 🔹 Updating State

```js
setNum(num + 5)
```

OR (Best practice ✅)

```js
setNum(prev => prev + 5)
```

---

### 🔹 Why `useState` is needed?

 Normal variable does NOT update UI

```js
let num = 0
num += 5   // UI will NOT change ❌
```

 Using `useState`

```js
setNum(num + 5)  // UI will update ✅
```

---

### 🔹 Key Difference

| Feature      | Normal Variable | useState |
| ------------ | --------------- | -------- |
| Value change | ✅               | ✅        |
| UI update    | ❌               | ✅        |
| Re-render    | ❌               | ✅        |

---

### 🔹 Event Handling Example

```js
const chngN = () => {
  setNum(prev => prev + 5)
}
```

```js
<button onClick={chngN}>Change N</button>
```

---

### 🔹 Flow

1. Button click
2. Function call
3. `setNum()` update value
4. React re-render
5. UI shows new value

---

### 🔹 Important Points

* State change is **asynchronous**
* Always use `setState` to update
* Avoid direct modification (`num = ...`)
* Prefer `prev => prev + value` for safety

---
