## Reusable Button Component (Props + Styling)
---
### 📁 Component: `Button.jsx`

```jsx id="n1"
const Button = ({ bgColor, text }) => {
  return (
    <button style={{ backgroundColor: bgColor }} className='btn-1'>
      {text}
    </button>
  );
};

export default Button;
```

---

### 💡 Explanation

* `Button` = reusable component
* `{ bgColor, text }` = props receive
* `bgColor` = button background color
* `text` = button label
* `style={{ backgroundColor: bgColor }}` = inline dynamic styling

---

## 📁 File: `App.jsx`

```jsx id="n2"
import './App.css'
import Button from "./components/Button/Button"

function App() {
  return (
    <>
      <Button bgColor="red" text="Click Me" />
      <Button bgColor="blue" text="Submit" />
      <Button bgColor="green" text="Save" />
    </>
  )
}

export default App;
```

---

## 🔹 Key Concepts

### ✅ 1. Props

* Used to pass data from parent → child
* Makes component dynamic

```jsx id="n3"
<Button bgColor="red" text="Click Me" />
```

---

### ✅ 2. Reusable Component

* Same component used multiple times
* Different output based on props

---

### ✅ 3. Inline Styling

```jsx id="n4"
style={{ backgroundColor: bgColor }}
```

* Dynamic styling using props
* Overrides CSS class if same property exists
