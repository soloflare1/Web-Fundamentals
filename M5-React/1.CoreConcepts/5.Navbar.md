##  Step 4: Convert to Reusable Component (Navbar)

📁 `Navbar.jsx`

```jsx id="s4"
import React from 'react';
import navImg from '../../assets/food.png';

const Navbar = () => {
  return (
    <nav className='nav-container'>
      <div className="nav-left">
        <img src={navImg} alt="food" />
        <p>Meal Hub</p>
      </div>

      <div className="nav-right">
        <p>Home</p>
        <p>About</p>
        <p>Contact</p>
        <p>Orders</p>
        <p>Blogs</p>
      </div>
    </nav>
  );
};

export default Navbar;
```

##  Step 5: Use Navbar in App.jsx
