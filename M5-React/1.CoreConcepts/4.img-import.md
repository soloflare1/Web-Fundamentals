##  React Image Import + Folder Structure 

---

## 📁 Project Folder Structure

```plaintext id="f1"
my-react-app/
│
├── src/
│   ├── assets/
│   │   └── food.png
│   │
│   ├── components/
│   │
│   ├── App.jsx
│   └── App.css
│
└── main.jsx
```

---

## 🖼️ Image Import Steps

###  Step 1: Put image inside `assets` folder

```plaintext id="f2"
src/assets/food.png
```

---

###  Step 2: Import image in component

```js id="f3"
import foodImg from './assets/food.png'
```

---

###  Step 3: Use in JSX

```jsx id="f4"
<img src={foodImg} alt="food" />
```

---

## ❌ Wrong Way

```jsx id="f5"
<img src="./assets/food.png" />
```
