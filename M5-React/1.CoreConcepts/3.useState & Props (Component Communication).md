

## 📁 File: `Home.jsx`

### 🔹 Create Component (shortcut: `rsc`)

```jsx id="n1"
import React from 'react';

const Home = ({ num }) => {
  return (
    <div>
      <h2>Home : {num}</h2>
    </div>
  );
};

export default Home;
```

---

### 💡 Explanation

* `Home` = child component
* `({ num })` = props receive
* `num` = data from parent (App)

---

## 📁 File: `App.jsx`

```jsx id="n2"
import { useState } from 'react'
import './App.css'
import Home from './Home'

function App() {
  const [num, setNum] = useState(0)

  const chngN = () => {
    setNum(prev => prev + 5)
  }

  return (
    <>
      <h1>{num}</h1>
      <Home num={num} />
      <button onClick={chngN}>Change N</button>
    </>
  )
}

export default App;
```

---

## 🔹 Key Concepts

### ✅ useState

```js id="n3"
const [num, setNum] = useState(0)
```

* `num` → current value
* `setNum` → update function

---

### ✅ Props

```jsx id="n4"
<Home num={num} />
```

* Parent → Child data pass

```jsx id="n5"
const Home = ({ num })
```

* Child receives props

---

## 🔄 Flow

1. Initial → `num = 0`
2. Button click
3. `setNum()` update
4. App re-render
5. Home gets new `num`
6. UI update ✔️

---

## ❗ Common Mistakes

### ❌ Wrong

```jsx id="n6"
<Home> num={num} </Home>
```

 Not props, just text

---

### ❌ Name mismatch

```jsx id="n7"
<Home n={num} />
const Home = ({ num })  // ❌
```

---

### ✅ Correct

```jsx id="n8"
<Home num={num} />
const Home = ({ num })  // ✔️
```

---

## 🧠 Easy Memory Trick

 **State (App) → Props → Child (Home)**
 “data always flows downward”

---
 **useState controls data, props send data to components**
